AQS及ReentrantLock原理分析

Created2023-08-20|Updated2023-10-02|java多线程并发
|Post View:

上一篇文章提到使用synchronized解决线程安全问题，这篇文章介绍另一种解决线程安全问题的方式-ReentrantLock，在介绍之前首先追踪一下它的原理，介绍java层面是怎么实现操作系统中的管程的，首先介绍它的抽象类-AQS，在AQS中有公平和非公平两种，文中也会对这两种原理进行分析，最后通过一个案例来解释ReentrantLock源码，会讲到公平锁和非公平锁是怎样加锁的，以及加锁失败怎样处理线程的，最后分析解锁的逻辑。

AQS原理

解决线程安全问题操作系统给我们提供了管程的概念，对于管程的实现分为jvm层面和java层面，其中jvm层面体现为synchronized，java层面则为AQS，在AQS中它同样的同步等待队列、阻塞队列、条件变量，当线程调用await时线程释放锁，线程进入阻塞队列中，调用signal时线程被唤醒进入同步等待队列中。
